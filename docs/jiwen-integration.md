# 积温（Jiwen）主动意识

SullyOS 已把 [jiwen](https://github.com/ClaraShafiq/jiwen) 的核心五轴模型接到“本地主动消息”流程。

## 开启方式

打开角色的「主动消息」设置，先打开主动消息，再打开「积温主动意识」。不开启时，原来的固定间隔主动消息行为不变。

## 它做什么

- 每次主动消息定时器到点时，先推进 `connection / pride / valence / arousal / immersion` 五个状态。
- 没有达到想念阈值时，本轮不发消息。
- 骄傲较高时，可能转为“自己找事做”，而不是硬发一条。
- 真正发消息时，会把状态描述和语气建议加入隐藏系统提示。
- 状态保存在浏览器的 localStorage：`sullyos.jiwen.v1.<角色ID>`。

## 主动消息 2.0 / Worker 路径

主动消息 2.0 也已经接通：fire_pack 会把积温配置上传到角色状态空间，Worker 到点读取并推进 `jiwen_state`。没有达到开口阈值时，Worker 会直接跳过本轮，不调用大模型，并在面板里显示“积温判断本轮没有主动开口”。

Worker 还没有部署时，本地路径照常可用；部署后，重新从设置页复制最新 Worker 代码即可启用云端判断。

## 目前没有接入的部分

jiwen 的“对话情绪分析”（需要另一个轻量模型返回 delta）还没有自动接入。SullyOS 已有自己的情绪评估流程，后续可以把评估结果映射到 Jiwen 的 `applyDelta()`，但需要先确定使用哪个模型和费用上限。
